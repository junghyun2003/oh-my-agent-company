# Marketing Playbook (Global + Korean-Friendly)

## Product Positioning
- Category: Local AI Agent Orchestration Console
- One-liner: "Run your own oh-my-agnet-company on a local machine with governance, approvals, and audit trails."
- Korean one-liner: "로컬 PC에서 승인/감사 기반으로 oh-my-agnet-company를 운영하는 실행형 콘솔"

## Ideal Customers
1. Solo builders and indie founders
2. Small software agencies
3. Internal ops teams needing traceable AI-assisted workflow

## Core Value Messages
1. Speed with control
- Parallel execution pipeline with owner approvals

2. Trust by default
- Append-only audit events and structured client response templates

3. Works on your machine
- Local-first runtime, simple startup, no mandatory cloud dependency

## Proof Points To Show Customers
- Pipeline visibility: PM -> CTO -> Dev(parallel) -> QA -> Report
- Governance controls: approval modes and repo path policies
- Reliability controls: worker hardening and DB lock retry
- Client-facing quality: 4-block response template

## Launch Assets Checklist
- README with bilingual value proposition
- LICENSE (clear OSS usage terms)
- 1-minute demo script
- Screenshot set for dashboard key flows
- "How to onboard in 30 minutes" quick guide

## Messaging Do/Don't
- Do: talk about outcomes (faster delivery, safer changes, audit-ready ops)
- Do: keep Korean and English docs aligned
- Don't: oversell "fully autonomous"
- Don't: hide known constraints (local runtime assumptions, policy setup needs)

## 30-Day Marketing Execution
1. Week 1
- Publish onboarding post (KR/EN)
- Add demo GIF/screenshot bundle

2. Week 2
- Collect first 3 external trial feedbacks
- Convert feedback into UX backlog issues

3. Week 3
- Publish "before/after" operational metrics
- Improve top 3 onboarding friction points

4. Week 4
- Release update note with customer-facing improvements
- Refresh pitch deck and README highlights
