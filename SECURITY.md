# Security Policy

## Reporting a Vulnerability
If you discover a security issue, please report it privately first.

Recommended report fields:
- affected component/file
- impact scope
- reproduction steps
- temporary mitigation

## Handling Policy
- High-risk findings are escalated to CTO/Tech Leader immediately
- QA may block release when risk is unresolved
- Post-fix, add audit evidence and update relevant policy docs

## Scope
Security-sensitive areas include:
- owner verification and write APIs
- repository policy enforcement
- approval gate controls
- audit integrity and report generation
