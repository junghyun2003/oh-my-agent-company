# Language Policy (Design Ops)

## Goal
- 한국어 사용자가 기본적으로 이해 가능한 UI를 유지한다.
- 글로벌 협업을 위해 핵심 용어는 영문 병기를 허용한다.

## Rules
1. 기본 라벨은 한국어를 우선한다.
2. 기술 용어는 필요 시 괄호 영문 병기한다. 예: `승인(approval)`.
3. 사용자 액션 버튼은 짧고 명확한 한국어를 우선한다.
4. 로그/감사/개발자용 문자열은 영문 포함 가능하되 의미가 모호하면 한국어 설명을 추가한다.
5. 동일 도메인 용어는 전 화면에서 동일 표기를 사용한다.

## Review Checklist
- 라벨이 한국어 우선인지
- 영문 병기가 과도하지 않은지
- 버튼/안내문이 사용자 행동을 명확히 유도하는지
- 고객 노출 텍스트에 내부 용어가 그대로 노출되지 않았는지
